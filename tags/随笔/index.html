以下是针对 HTML 和 CSS 的必备知识清单，涵盖学习深度、面试重点和实际应用场景，并标注了哪些是核心必学，哪些是进阶加分项。你可以对照检查自己的掌握情况。

  • 详解下，关键知识点可以进行补充与适当拓展

HTML 与 CSS

一、HTML 必备知识

[[1. 基础结构与语义化（核心必学）]]

  • DOCTYPE 声明：<!DOCTYPE html> 的作用。
  • 基本结构：<html>、<head>、<body> 的用途。
  • 语义化标签（面试高频）：
    • <header>、<footer>、<nav>、<article>、<section>、<aside>
    • 为什么用语义化标签？（SEO、可访问性、代码可读性）
  • 常用标签：
    • 文本：<h1>~`
      、

      、、、`

    • 列表：<ul>、<ol>、<li>
    • 表格：<table>、<tr>、<td>、<th>（简单了解，现代开发较少用）
    • 表单：<form>、<input>、<textarea>、<select>、<button>

✅ 面试常见问题：

  • “什么是 HTML 5 语义化？举例说明。”
  • “<div> 和 <section> 的区别是什么？”

[[2. 表单与交互（核心必学）]]

  • 表单属性：action、method（GET/POST）、name、placeholder、required
  • Input 类型：text、password、email、number、date、checkbox、radio
  • 表单验证：HTML 5 原生验证（如 pattern、min、max），对比 JS 验证的优缺点。

✅ 面试常见问题：

  • “如何实现一个带验证的登录表单？”
  • “GET 和 POST 请求的区别？”

[[3. 元信息与性能优化（进阶）]]

  • <meta> 标签：charset、viewport（移动端适配）、description（SEO）
  • 资源加载：<script> 的 async 和 defer 区别（面试高频）。
  • 预加载：<link rel="preload">、<link rel="preconnect">

二、CSS 必备知识

[[1. 基础选择器与盒模型（核心必学）]]

  • 选择器：
    • 基础：#id、.class、tag
    • 组合：div p（后代）、div > p（子元素）、div + p（相邻兄弟）
    • 伪类/伪元素：:hover、:focus、::before、::after（面试高频）
  • 盒模型：
    • content-box vs border-box（面试必问）
    • margin、padding、border 的用法和塌陷问题

✅ 面试常见问题：

  • “如何让一个元素水平垂直居中？”（至少掌握 3 种方法）
  • “box-sizing: border-box 的作用是什么？”

[[2. 布局技术（核心必学）]]

  • 传统布局：
    • float + clearfix（了解即可，现代开发少用）
    • position：relative、absolute、fixed、sticky（面试高频）
  • Flexbox（必学）：
    • display: flex、justify-content、align-items、flex-direction
    • 实现响应式导航栏、卡片布局
  • [[Grid]]（加分项）：
  • grid - CSS：层叠样式表 | MDN
    • display: grid、grid-template-columns、gap
    • 实现复杂网格布局

✅ 面试常见问题：

  • “Flexbox 和 Grid 的区别？各自适用场景？”
  • “如何实现一个圣杯布局？”

[[3. 响应式设计（核心必学）]]

  • 媒体查询（Media Queries）：
    • @media (max-width: 768px) 适配移动端
  • 移动端适配：
    • viewport 设置：<meta name="viewport" content="width=device-width, initial-scale=1">
    • 单位选择：rem（基于根字体）、vw/vh（视窗单位）

✅ 面试常见问题：

  • “如何实现一个响应式网页？”
  • “px、em、rem 的区别？”

[[4. 动画与性能（进阶）]]

  • 过渡与动画：
    • transition：hover 渐变效果
    • @keyframes + animation：复杂动画
  • 性能优化：
    • 减少重绘（will-change）、使用 transform 代替 top/left

三、检查清单：你是否掌握了这些？

HTML 部分

  • 能写出符合语义化的 HTML 5 结构。
  • 能实现一个带验证的表单。
  • 理解 <script> 的 async 和 defer 区别。

CSS 部分

  • 能用 Flexbox 实现常见布局（如导航栏、卡片列表）。
  • 能处理盒模型塌陷问题（如 margin-collapse）。
  • 能使用媒体查询实现响应式设计。

四、面试必备知识总结

分类 核心知识点 面试频率
HTML 语义化标签、表单、<meta> 标签、async/defer ⭐⭐⭐⭐
CSS 盒模型、Flexbox、Grid、居中方案、响应式设计 ⭐⭐⭐⭐⭐
加分项 CSS 动画、性能优化、BEM 命名规范 ⭐⭐

五、学习建议

  1. 优先掌握核心内容（语义化 HTML、Flexbox、响应式设计）。
  2. 动手实践：
    • 用 HTML+CSS 克隆一个 Apple 官网首页（练习布局与响应式）。
    • 实现一个 交互式导航栏（hover 效果 + 移动端适配）。
  3. 面试前重点复习：
    • 盒模型、Flexbox、居中方案、媒体查询。

如果有遗漏或想深入某个知识点，可以告诉我！ 💪

JS

以下是结合你的需求（为学习 React 做准备）设计的 JavaScript 高效学习路径，分阶段标注关键知识点、推荐资源及学习方法，并整合了多个权威来源的建议。

[[阶段一：JavaScript 核心基础（2-3 周）]]

目标：掌握语法基础，为 React 组件化开发打底。
关键知识点：

  1. 变量与数据类型：let/const、基本类型（字符串、数字、布尔）、引用类型（对象、数组）。
  2. 函数与作用域：函数声明、箭头函数、闭包、作用域链、this 指向。
  3. 数组方法：map、filter、reduce（React 中高频使用）。
  4. 控制结构：if-else、for / while 循环、switch。

学习资源：

  • 教程：MDN JavaScript教程（权威文档）。
  • 书籍：《JavaScript 高级程序设计》第 1-4 章（重点：数据类型、函数）。
  • 实践平台：Codecademy JavaScript Track（互动练习）。

学习方法：

  • 每日练习：[[用原生 JS 实现计算器、待办事项列表（DOM 操作入门）]]。
  • 调试技巧：使用 Chrome DevTools 的 console.log 和断点调试。

[[阶段二：ES 6+与函数式编程（2 周）]]

目标：掌握 React 依赖的现代语法与函数式思维。
关键知识点：

  1. ES 6+特性：箭头函数、解构赋值、模板字符串、展开运算符。
  2. 模块化：import/export 语法（React 项目必备）。
  3. 函数式编程：纯函数、高阶函数、不可变性（React 状态管理基础）。

学习资源：

  • 教程：阮一峰ES6入门教程（免费开源）。
  • 书籍：《JavaScript 高级程序设计》第 5-7 章（面向对象与函数式）。
  • 视频：YouTube 频道 The Net Ninja（ES 6 系列）。

学习方法：

  • 项目实践：用 ES 6 语法重构阶段一的代码（如改用箭头函数、解构赋值）。
  • 代码规范：使用 ESLint 或 WebStorm 的 JSHint 插件检查代码风格。

[[阶段三：异步编程与 API 交互（1-2 周）]]

目标：掌握 React 中数据请求的核心技能。
关键知识点：

  1. 异步处理：Promise、async/await、try...catch。
  2. API 调用：使用 fetch 或 axios 获取数据。
  3. 错误处理：网络请求失败时的兜底策略。

学习资源：

  • 教程：JavaScript.info异步章节（深度解析）。
  • 实战项目：调用 OpenWeatherMap API 实现天气应用（整合 DOM 与异步）。

学习方法：

  • 模拟数据：使用 JSONPlaceholder 练习 REST API 调用。
  • 调试技巧：用浏览器 Network 面板分析请求与响应。

[[阶段四：DOM 操作与事件处理（1 周）]]

目标：理解 React 底层机制（虚拟 DOM 抽象原理）。
关键知识点：

  1. DOM 操作：querySelector、createElement、appendChild。
  2. 事件模型：事件冒泡/捕获、addEventListener。
  3. 动态渲染：根据数据生成 DOM 元素（类似 React 的 JSX 原理）。

学习资源：

  • 书籍：《JavaScript DOM 编程艺术》（适合入门）。
  • 实战项目：实现动态问答应用（点击切换问题，类似 React 组件切换）。

学习方法：

  • 对比学习：用原生 JS 实现 React 组件的基础功能（如动态列表渲染）。
  • 性能优化：减少重绘（如使用 documentFragment）。

[[阶段五：模块化与工具链（1 周）]]

目标：熟悉 React 项目的工程化环境。
关键知识点：

  1. 模块化开发：ES 6 模块化语法、CommonJS 与 ESM 的区别。
  2. 构建工具：Vite（React 推荐工具链）。
  3. 包管理：npm / yarn 安装依赖。

学习资源：

  • 文档：Vite官方文档（快速搭建 React 项目）。
  • 实践：用 Vite 初始化一个 JS 项目，体验模块化与热更新。

[[阶段六：React 前置知识强化（1 周）]]

目标：针对性学习 React 依赖的核心概念。
关键知识点：

  1. 组件化思维：理解函数组件与类组件的差异。
  2. JSX 语法：掌握 HTML 与 JS 混合编写的逻辑。
  3. 状态管理基础：useState、useEffect（React Hooks）。

学习资源：

  • 教程：React官方文档 Beta版（优先学习）。
  • 实战项目：用原生 JS 模拟 React 组件状态更新（如计数器）。

学习节奏与工具推荐

  • 每日投入：建议每天 2 小时，周末集中做项目。
  • IDE 推荐：VSCode（免费）或 WebStorm（付费，集成 React 支持）。
  • 避坑指南：
    • 避免过早学习 Redux，先用 React 内置状态管理。
    • 不要依赖 jQuery（React 生态已淘汰直接 DOM 操作）。

总结：React 学习前置知识图谱
